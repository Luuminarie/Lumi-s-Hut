# Lumi's Hut

A lightweight, responsive portfolio with a desktop-inspired interface, animated SVG waves, and light and dark themes. It is built with plain HTML, CSS, and JavaScript; there are no build steps or dependencies.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. For example:

```sh
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Explore

- Select icons in the dock to open About, Now & learning, Fun facts, and Find me windows.
- Drag a window by its title bar. Use its controls to close, minimize, or maximize it; press Escape to close the active window.
- Use the button in the top-right corner to switch themes. Your choice is saved in this browser.
- The interface respects reduced-motion preferences.
